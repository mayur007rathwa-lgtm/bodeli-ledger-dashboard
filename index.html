About the data and filters

Data comes only from the LDG text file(s) you upload. Consumption = CONSUMPTION_UNIT. Theft + Litigation Arrears = THEFT_ARREARS + LITIGATION_ARREARS. Meter No = METER_NO. Solar Consumer = SOLAR_CONSUMER (Y/N). BLANK or NOT MAPPED means the ledger cell is empty.

Upload LDG text file: choose one or more ledger text exports (for example 034LDG102026.txt, '|' separated with a header row). Several subdivision files can be chosen together. The file is read only in your browser and is not saved to the dashboard, so after a page reload it has to be uploaded again.

Consumer search matches any part of the consumer number, name or village. Meter search ignores spaces, dashes, dots and capital letters, so "mgvcl1880351", "MGVCL_1880351" and "1880351" all find the same meter. Filters work like Excel: press ▾ on a filter or column, tick one or more values, and press Apply. Type in the filter search box to narrow the list. If nothing in the list matches what you typed, Apply keeps every value that contains the typed text. Connection Date and PDC Date are grouped by month: tick a whole month, or open it with ▸ and tick single dates. Filters on different columns work together.
